# Google Sheets sync

**Status: experimental / unsupported.**

The repository retains the legacy `sheet-sync/` script for existing users who may still rely on it. It is not part of the Android app's supported workflow, has no supported release/test contract, and should not be used for new installations. No active-user or owner-rationale evidence was available during this refactor, so the script is isolated rather than silently deleted.

Do not add new dependencies or expand this integration without an explicit maintainer decision, documented ownership, security review and tests. Keep credentials out of source control.
